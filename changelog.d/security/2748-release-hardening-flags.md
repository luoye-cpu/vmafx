- **Every Linux release binary now builds with the documented hardening flags (issue 2748)** — `_FORTIFY_SOURCE=3`, `-fstack-protector-strong`, PIE (`-fPIE`, `-pie`) and full RELRO (`-Wl,-z,relro,-z,now`) are defined once in `core/native/release-hardening.ini` and applied to the native bundle, the release container images and the Linux wheels through `--native-file`; `scripts/release/check_release_hardening.py` fails a release whose staged artifacts do not carry the resulting properties (PIE flag, PT_GNU_RELRO with BIND_NOW, `__stack_chk_fail`/`__*_chk` imports), and the published images' `/usr/local/bin/vmaf` no longer carries the Meson build-tree run path (`$ORIGIN/../src` is removed from the staged copy).
