- **The RC5 run-result timeline has a schema skeleton.** `api/run-result-timeline.schema.json` defines the versioned document that will carry one run's provenance, per-frame scores, per-window statistics and events across the CLI, the C API and the server (#2452); it follows the closed-object model of ADR-3538 (a schema-owned member, required or optional, or a new event type takes a new `schema_version`), and the acceptance fixtures in `api/testdata/run-result-timeline/` pin the shape in `scripts/ci/tests/test_run_result_timeline_schema.py`. `scripts/ci/run_result_timeline_contract.py` combines the JSON Schema with the named OpenAPI components and the frame/window/event ordering rules the schema cannot state. The writer/reader C ABI and the byte-equal write-read-write identity check land in the follow-up PRs of the same issue.
