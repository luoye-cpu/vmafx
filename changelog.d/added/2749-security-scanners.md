- **Security gates:** CI now audits every project Python lock with `pip-audit` and scans the root `Dockerfile` image with Trivy; each gate first rejects a planted vulnerable fixture, and retained findings need a dated exception. The image lane also runs for the packaging and Python lock files that feed the Docker build. A package-scoped Rego policy drops kernel CVEs reported against the header-only `linux-libc-dev` package, while the planted-image control proves the policy is neither broken nor over-broad. Before the image build, `trivy convert --ignore-policy` runs the policy against a committed two-finding report; it fails if the kernel finding remains or the `libssl3t64` control finding is dropped, so a policy that does not parse under Trivy 0.76 cannot reach the scan. `pip-audit` accepts CVE, GHSA and PYSEC identities for the planted advisory, including aliases.
