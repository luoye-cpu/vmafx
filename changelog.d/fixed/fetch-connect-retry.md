- **CI:** a refused or unreachable connection no longer ends a CI download on the first attempt: curl and wget fetches in shell scripts, workflows and container recipes retry connection and host-resolution failures, the tidy lane's APT downloads retry, and a contract test checks curl and wget fetches for the retry flags and requires retried downloads to write to a file before use. Network `git clone` calls go through one shared bounded-retry helper, including the `git -c <key>=<value> clone` form the upstream-consumer compat scripts use and the `git -c`/`git -C` shapes the contract test now matches.
