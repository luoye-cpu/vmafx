- **`test_to_xml` is re-enabled with its golden value unchanged.** `Result.to_xml()` now emits attributes in the recorded order (score keys first, then `frameNum`/`method` — the order xml.dom.minidom produced before Python 3.8, when the golden string was written) and renders score floats by default with Python 2's 12-digit `str(float)` semantics, so the golden XML is byte-stable on every supported interpreter instead of depending on minidom's version-bound attribute handling and repr formatting. Note for callers: XML attribute values are now rounded to 12 significant digits by default (`to_dict()`/`to_json()` keep full precision, and `to_xml(full_precision=True)` restores it, mirroring the CLI's `--precision=max`). The bootstrap comparison (`_bootstrap_correlations`) draws its resamples with an explicit legacy `RandomState(seed_resample)` — the same sequence the golden was recorded with, without mutating global RNG state — and `_correlation_stat` returns NaN for resampled columns without two distinct values, where the old pandas stack returned NaN silently and today's scipy-backed spearman warns (which `filterwarnings = error` in `python/tox.ini` would escalate). `test_compare_two_quality_runners_on_dataset` stays skipped: its golden expectations are only reachable when the dataset's two flat assets are tied in the correlation input, which only the recording build produced (live builds separate the pair by 1.1e-12 to 2.18e-4 with the ordering flipping between builds); the library does not quantize predictions to reproduce one build's ties — rounding inside the public statistic changes PLCC/SROCC for 0..1 scorers — so the skip reason now names the measured separation.
