- **`test_to_xml` and `test_compare_two_quality_runners_on_dataset` are re-enabled with their golden values unchanged.** `Result.to_xml()` now emits attributes in the recorded order (score keys first, then `frameNum`/`method` — the order xml.dom.minidom produced before Python 3.8, when the golden string was written) and renders score values with Python 2's 12-digit `str(float)` semantics, so the golden XML is byte-stable on every supported interpreter instead of depending on minidom's version-bound attribute handling and repr formatting. The bootstrap comparison draws its resamples with an explicit legacy `RandomState(seed_resample)` (the same sequence the golden was recorded with, without mutating global RNG state) and correlates at thousandth resolution, returning NaN for resampled columns without two distinct values: the recorded expectations were taken on a build that scored the dataset's two flat assets identically, and the raw separation observed across the fork's builds (1.1e-12 to 2.18e-4, ordering flipping) is build noise, so sub-threshold differences are ties and only grid-level differences rank. The old pandas stack returned NaN for constant columns silently; today's scipy-backed spearman warns, and `filterwarnings = error` in `python/tox.ini` would fail the test on it.
