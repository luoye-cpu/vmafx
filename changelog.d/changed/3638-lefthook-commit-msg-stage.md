- **The lefthook commit-msg stage runs the framework's Conventional Commits check (issue #3638).** `lefthook.yml` declares `commit-msg` and hands the message file to `scripts/git-hooks/framework-hooks.sh`, whose new branch runs the same `hook-impl` entry the ADR-1241 dispatcher uses, so a lefthook-only checkout validates commit messages locally and the squash-merge judge stops skipping the check. A planted non-conventional subject (`update stuff`) refuses through the real framework and a conventional subject passes (`scripts/githooks/tests/test_commit_msg_hook.py`); the bridge tests pin the wiring and the installer keeps lefthook's shim in place.
